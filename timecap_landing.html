naked code

코드를
숨기지 않는다

화면 캡처 앱은 시스템 권한이 필요하다.
그 신뢰는 투명성으로 얻는다.
AI에게 던지면 30초 만에 검증 가능한
심플함을 유지한다.

  • captures screen every 10s via screencapture
  • saves to ~/timecap/ only
  • no network calls
  • no external data transfer
  • source: View Source → verify yourself or ask AI

def capture_tick(self, _):
  path = FileManager.new_capture_path()
  result = subprocess.run(
    ["screencapture", "-x",
     "-t", "jpg", path],
    timeout=15
  )

def view_source(self, _):
  subprocess.run(
    ["open", "-t", SOURCE_FILE]
  )
how it works

레고 블록처럼.
각 단계가 독립적으로.

Block 1
Capture
Start Capture 후 10초마다 자동 촬영. screenshots/ 에 쌓인다.
자동
Block 2
Make Video
30장 이상일 때 실행. ffmpeg으로 타임랩스 mp4 생성.
수동
Block 3
Archive Move
사용된 jpg를 archive/YYYYMM/ 으로 이동. 월별 정리.
수동
Block 5
Log
실패, idle 스킵, timeout 자동 기록. logs/ 폴더에 일자별.
자동
